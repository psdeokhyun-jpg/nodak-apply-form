## 왜 원격(웹/아이폰) 세션에서는 ChatGPT/Gemini 접근이 안 되는가

| | 맥 로컬 세션 | 웹/원격 세션 |
|---|---|---|
| 실행 위치 | 맥 | 클라우드 컨테이너 |
| MCP 서버 | `~/.claude.json` 에 등록된 로컬(stdio) 서버 전부 | 없음 (`mcpServers: {}`) |
| 커넥터 | 계정 커넥터 + 로컬 MCP | 계정 커넥터만 |

로컬 stdio 방식 MCP 서버는 그 컴퓨터에서 실행되는 프로세스라 원격 컨테이너에는
존재하지 않습니다. 기기(맥/아이폰)의 문제가 아니라 세션 종류의 문제입니다.

원격에서도 쓰려면 해당 MCP 서버를 HTTP/SSE 방식으로 올린 뒤 claude.ai에
커스텀 커넥터로 등록해야 합니다. 임시 방편으로는 ChatGPT 공유 링크
(`chatgpt.com/share/…`)를 만들어 전달하면 공개 URL이라 원격에서도 읽힙니다.
